**iceDesk** 是一个极致轻量、极简纯粹的安卓桌面（Launcher）应用。它的核心功能是配合 **冰箱**、**小黑屋** 或 **Shizuku** 进行应用冻结与解冻。

✨ **核心痛点解决**
* ❌ **传统桌面痛点**：冻结应用后，桌面图标会立刻消失，寻找极不方便，解冻后图标顺序还会被打乱。
* ✅ **iceDesk 桌面**：在冻结 App 之后，**桌面上的图标依然完好保留**，绝不消失！

📦 **应用信息**
* **软件包名**：`cn.lalaki.desk`
* **软件大小**：**876 KB**
* **系统要求**：Android 9 及更高版本系统。
* **下载地址**：[见页面底部](./README.md#%E9%A6%96%E9%80%89%E5%9C%B0%E5%9D%80)

## 🛠️ 功能特性

### 1. 📂 桌面与图标交互
* **桌面时钟组件**：
  * **单击**：打开系统自带时钟 App。
  * **双击**：进入 iceDesk 设置界面。
  * **长按**：开启图标排序。排序模式下，单击应用图标可自定义名称、更换应用图标或隐藏应用。
  * **手势**：下滑展开通知栏，上划关闭屏幕（需 Shizuku）。
* **个性化支持**：
  * 完美兼容第三方图标包（Icon Pack）。
  * 自定义应用图标与应用名称。
  * 选取自定义图片作为应用图标。
* **侧滑应用列表**：在屏幕右侧滑动即可快捷切换到指定 App（需悬浮窗权限）。
* **一键锁屏图标**：
  * 长按桌面“一键锁屏”图标，可唤出进入桌面设置、打电话、打开浏览器等快捷菜单。
  * 一键锁屏图标还可以添加到状态栏，通过编辑状态栏上的功能块就能找到它。

### 2. 💡 一些创意小功能（这里的大部分功能需要 Shizuku）
* **短信相关**：集成短信收发功能，支持关键词拦截，可通过配置 SMTP 将短信自动转发至指定邮箱。
* **通话相关**：支持自动接听（营销电话的克星）及来电静音。
* **性能调节**：集成了 Uperf 模块模式调节选项，支持自定义模式以及息屏切换到指定模式。
* **桌面隐藏**：在桌面时按下 **音量- 键** 可瞬间隐藏桌面，双击 **音量- 键** 即可恢复。
* **物理唤醒**：支持通过音量键唤醒屏幕。

## 🎯 项目说明

### 为什么它如此极简？
这个桌面最初是为我的备用机量身打造的。本着“够用就好”的原则，去除了小部件、分页、文件夹归类等繁琐功能，只专注打磨我自己想要的核心功能。

### 关于源码与环境
由于部分历史源码丢失，且早期（2020年萌新时期）代码中引入了一些复杂的本地编译依赖，导致目前外部环境极难复现。因此本项目目前仅提供编译好的稳定成品，暂不发布源码。
